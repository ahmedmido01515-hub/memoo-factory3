# سورس ميمو - Source Memo

أقوى مصنع بوتات حماية تليجرام بالعربي

**قناة السورس:** https://t.me/Memoofactory
**مطور السورس:** @MernaQueen
**بوت المصنع:** @memoo_factory_bot

## المميزات
- صنع بوت حماية مجاني بضغطة زر
- صنع بوت مدفوع بمميزات VIP
- لوحة تحكم سهلة
- كود نظيف وباللهجة المصرية

## التشغيل
1. حط التوكن في config.py
2. شغل `pip install -r requirements.txt`
3. شغل `python main.py`
